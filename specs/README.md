# Especificações de produto e engenharia

Cada entrega com mudança funcional, técnica relevante ou de dados deve ter uma especificação neste diretório antes da implementação.

## Como usar

1. Copie `TEMPLATE.md` para um arquivo com o próximo número disponível: `0001-nome-da-entrega.md`.
2. Preencha objetivo, escopo e critérios de aceite antes de alterar código.
3. Durante a implementação, registre decisões que alterem o plano técnico.
4. Ao concluir, marque os critérios atendidos e anote a validação realmente executada.

Uma spec é um registro histórico: não a apague para reutilizar o número. Correções exclusivamente mecânicas, sem mudança de comportamento, podem não exigir spec conforme as regras em `AGENTS.md`.
